## 8. push / pull 演练（本地裸仓库）

```text
$ git push -u origin main
branch 'main' set up to track 'origin/main'.
 * [new branch]      main -> main

$ git clone ...\origin.git ...\clone
Cloning into '...\clone'... done.

$ git push origin main        # 在 clone 中提交后
87c4370..7051979  main -> main

$ git pull --rebase origin main
Updating 87c4370..7051979
Fast-forward
 README.md | 3 +++
 1 file changed, 3 insertions(+)
```

远端为本地裸仓库，用于在无 GitHub 凭据时验证完整同步流程；
换成 `git@github.com:<用户名>/<仓库>.git` 后操作一致。
