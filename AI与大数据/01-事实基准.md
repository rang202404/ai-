## 2. 网络事实（决定采集方案）

| 目标 | 结果 | 证据 |
| --- | --- | --- |
| `api.github.com` | 可用，约 2 秒返回 | `curl -m 30 https://api.github.com/repos/pallets/flask` → 200 |
| `raw.githubusercontent.com` | **被阻断**，30 秒超时 | `curl` 返回 code=000 |
| `codeload.github.com` | 可用但很慢（740KB 约 44 秒） | `curl` 200 / time 43.99s |
| `cdn.jsdelivr.net` | 可用且快（67KB 约 1.5 秒） | `curl` 200 / time 1.54s |
| `data.jsdelivr.com` | 可用，可列 GitHub 仓库文件树 | 拉取 flask 236 个文件清单成功 |

结论：语料采集采用 **GitHub API 取元数据/许可证/sha + jsDelivr 镜像取文件内容**。
这一组合不改变"语料来自 GitHub"的事实：内容与 sha 均对应 GitHub 仓库的同一 commit。
