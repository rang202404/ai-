# 00 项目章程与范围

## 1. 目标

在 `D:\test` 内交付一个**可运行、可验证、可追溯**的最小 RAG 项目：

1. 用 AI 协作契约与事实基准文档，压掉模型幻觉空间；
2. 以 GitHub 公共仓库为语料，Python 脚本完成「采集 → 切块 → 索引 → 检索 → 回答 → 落盘 `.py`」；
3. 补齐 GitHub 账号、Git 安装配置、pull/push、LICENSE 四类工程交付说明。

## 2. 范围内（In Scope）

- GitHub 语料采集（3 个宽松许可证仓库，固定 commit）；
- 代码/文档混合切块、BM25 + 字符向量双路召回、RRF 融合、覆盖率拒答；
- DeepSeek 生成（可选）+ 零 Key 抽取式降级；
- 回答引用可回溯到 `仓库/路径/行号`；
- Git 本地仓库初始化、提交、与裸仓库之间的 push/pull 演练；
- LICENSE（代码 MIT + 文档 CC BY 4.0）与第三方许可证说明。

## 3. 范围外（Out of Scope）

- 向量数据库、embedding 模型、GPU 推理；
- GitHub 账号真实注册与真实远端 push（需要用户本人邮箱/凭据，见 `docs/01`）；
- 生产级鉴权、并发、增量索引；
- 对所有 GitHub 仓库的全量覆盖。

## 4. 交付物清单

| 编号 | 交付物 | 位置 | 验收方式 |
| --- | --- | --- | --- |
| D1 | AI 协作契约 | `agent.md` | 人工阅读 + 规则可执行 |
| D2 | 反幻觉文档集 | `AI与大数据/*.md` | 事实可复核、口径一致 |
| D3 | RAG 实现 | `rag/*.py` | `pytest` 全绿 + `scripts/evaluate.py` 5/5 |
| D4 | 采集/建库/问答脚本 | `scripts/*.py` | 实际跑通并留下输出 |
| D5 | 生成的 `.py` 产物 | `examples/generated/*.py` | `ast.parse` 通过 |
| D6 | GitHub/Git/LICENSE 文档 | `docs/*.md` | 命令可复制执行，版本号与实测一致 |
| D7 | 验证记录 | `docs/05-验证记录.md` | 含时间戳与真实输出 |

## 5. 成功标准

- 针对语料内问题，回答有引用且引用可在索引中定位；
- 针对语料外问题，系统拒答而不是编造；
- 全部测试与验收脚本通过；
- 任意第三方按文档可从零复现（除需要个人凭据的 GitHub 远端操作）。
