# 02 技术栈与运行环境

## 1. 结论先行

| 项 | 选择 | 原因 |
| --- | --- | --- |
| Python | 3.11.18（conda `test` 环境） | 稳定、wheel 覆盖广；与文档版本一致 |
| 运行期依赖 | **仅标准库** | 离线可跑、无供应链风险、评审可读 |
| 测试 | pytest 9.1.1 | 已在 `test` 环境，用例集中在 `tests/` |
| 检索 | BM25 + 字符 n-gram 哈希向量 + RRF | 无 embedding 服务也能工作，结果可解释 |
| 生成 | DeepSeek `deepseek-chat`（可选） | OpenAI 兼容接口，`urllib` 直连即可 |
| 索引 | gzip JSON | 无数据库依赖，可 diff、可审计 |

## 2. 环境位置与激活

| 项 | 值 |
| --- | --- |
| conda 可执行文件 | `D:\working area\Scripts\conda.exe` |
| 环境根目录 | `D:\working area\envs\test` |
| Python | `D:\working area\envs\test\python.exe` |
| 环境规格文件 | `environment.yml`（项目根目录） |

激活方式（三选一）：

```powershell
# A. Anaconda PowerShell Prompt（安装目录自带快捷方式）
conda activate test

# B. 普通 PowerShell（当前用户未做 conda init）
(& "D:\working area\shell\condabin\conda-hook.ps1"); conda activate test

# C. 不激活，直接指定解释器
& "D:\working area\envs\test\python.exe" -m rag.cli stats
```

重建环境：

```powershell
conda env create -f D:\test\environment.yml
```

> conda 路径含空格会触发警告；不要为此改环境位置，除非要编译 C 扩展。

## 3. 依赖边界

- `requirements.txt` 声明：运行期无第三方包；测试期 `pytest`。
- `environment.yml` 是唯一的环境事实来源；新增依赖必须同时在两处登记。
- 不得为了"方便"引入 `langchain`、`chromadb`、`sentence-transformers` 等重型栈——本项目刻意保持可审计。

## 5. 环境变量

| 变量 | 必需 | 默认 | 作用 |
| --- | --- | --- | --- |
| `DEEPSEEK_API_KEY` | 否 | 空 | 配置后走生成式回答；不配则走抽取式引用 |
| `DEEPSEEK_BASE_URL` | 否 | `https://api.deepseek.com` | OpenAI 兼容网关 |
| `DEEPSEEK_MODEL` | 否 | `deepseek-chat` | 模型名 |
| `GITHUB_TOKEN` | 否 | 空 | 提高 GitHub API 配额（60→5000 次/小时） |
| `RAG_DATA_DIR` | 否 | `<项目>/data` | 语料/索引目录 |
| `RAG_ARTIFACT_DIR` | 否 | `<项目>/examples/generated` | `--save-code` 默认目录 |

示例见项目根目录 `.env.example`。**不要把真实 Key 写进仓库**。

## 6. Windows 注意事项

1. 控制台中文：在 PowerShell 中先执行
   `[Console]::OutputEncoding=[Text.Encoding]::UTF8; $env:PYTHONIOENCODING='utf-8'`，
   否则重定向输出可能乱码（文件本身始终是 UTF-8）。
2. 路径含空格：conda 会警告；调用时始终给路径加引号。
3. 换行：`.gitattributes` 已配置 `text=auto`，避免 CRLF 污染 diff。
4. 代理：本机 WinINET 代理项存在但 `ProxyEnable=0`，Python 默认直连；如开启代理需同步设置 `HTTPS_PROXY`。
