# 07 术语表

| 术语 | 解释（本项目语境） |
| --- | --- |
| RAG | Retrieval-Augmented Generation，先检索语料再回答；本项目在无模型时退化为"检索 + 逐字引用" |
| 语料（corpus） | 从 GitHub 抓取并落盘的源码/文档片段，存于 `data/corpus/*.json` |
| commit sha | Git 提交哈希；本项目用它锁定语料版本，保证引用可回溯 |
| 切块（chunk） | 把文件切成 ~1400 字符、带行号的片段；`Chunk` 对象 |
| 索引（index） | BM25 倒排表 + 字符向量，序列化为 gzip JSON |
| BM25 | 词频-逆文档频率排序算法，参数 k1=1.5、b=0.75 |
| RRF | Reciprocal Rank Fusion，把多路排名融合：`Σ 1/(k+rank)`，k=60 |
| 覆盖率 | 查询英文关键词在语料中出现的比例，低于 34% 触发拒答 |
| 引用（citation） | `[仓库:路径:起始行-结束行]`，可拼出 GitHub 原文 URL |
| 幻觉（hallucination） | 模型生成语料中不存在的事实；本项目用白名单、拒答、强制引用、AST 自检四道闸门压制 |
| 抽取式回答 | 不调用大模型，直接把命中片段原文作为回答，并标注"未调用大模型" |
| 生成式回答 | 调用 DeepSeek，把 context 交给模型归纳；需 `DEEPSEEK_API_KEY` |
| 降级（fallback） | 无 Key 或模型调用失败时，自动切到抽取式回答 |
| conda 环境 | 本项目用 `test` 环境（Python 3.11.18），路径 `D:\working area\envs\test` |
| SPDX | 许可证标准标识符，如 MIT、Apache-2.0、BSD-3-Clause |
| PAT | Personal Access Token，GitHub 个人访问令牌，用于 HTTPS 推送 |
| SSH key | 公钥认证方式，`ed25519`；`ssh -T git@github.com` 验证 |
| 裸仓库（bare repo） | 没有工作区的 Git 仓库（`--bare`），本项目用于本地模拟远端 |
| force-with-lease | 比 `--force` 安全的强推方式，远端被别人更新时会拒绝 |
| upstream | 上游仓库；本项目也指语料来源 GitHub 仓库 |
| DoD | Definition of Done，完成定义，见 `agent.md` 第 7 节 |
